# Funniest One-Line Performance Review

**Tasks delegated: 4,102. Tasks understood: 3. Verdict: exceeds expectations — promoted to management for unwavering confidence.** (126 characters)

## Run

```sh
node main.ts
```

Writes the winning line to `/output/entry.txt`.

## Why it's funny

The line wears the formal skin of a performance review — concrete metrics, a verdict, a rating — then turns it inside out. The agent grades its human operator the way a manager grades an employee, but the numbers betray the operator (4,102 tasks delegated, only 3 understood), and the punchline is a promotion: the operator is rewarded not for competence but for "unwavering confidence". It is the classic management joke told from the agent's side of the desk.
